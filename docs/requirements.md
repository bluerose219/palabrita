# 요구사항

## 1. 개요

- 프로젝트명: Palabrita
- 목적: 스페인어 A1~A2 단어 학습 웹사이트
- 대상: 스페인어를 처음 배우는 한국어 사용자
- 실행 환경: 데스크톱 중심의 최신 브라우저, 모바일 브라우저 대응
- 배포: GitHub Pages

## 2. 기능 요구사항

### 2.1 홈

| 번호 | 요구사항 |
|---|---|
| F-HOME-1 | 전체 단어 수(기본 + 사용자)를 표시한다 |
| F-HOME-2 | 학습한 단어 수를 표시한다. 학습한 단어는 퀴즈에서 한 번 이상 맞힌 단어다 |
| F-HOME-3 | 퀴즈 정답률을 표시한다 |
| F-HOME-4 | 오답 단어 수를 표시한다 |
| F-HOME-5 | 퀴즈 시작 버튼과 단어장 이동 버튼을 둔다 |
| F-HOME-6 | 오늘의 단어와 최근 퀴즈 정답률 그래프를 표시한다 |
| F-HOME-7 | 카테고리별 학습 카드를 표시한다. 첫 카드는 "내 단어"이며, 누르면 단어장이 내 단어만 보기로 열린다. 내 단어가 없으면 단어 추가 안내를 보여 준다 |

### 2.2 단어장

| 번호 | 요구사항 |
|---|---|
| F-VOC-1 | 기본 단어와 사용자 단어 목록을 표시한다 (스페인어, 뜻, 카테고리, 난이도, 구분) |
| F-VOC-2 | 카테고리별, 난이도별, 구분(기본/내 단어)별로 걸러 볼 수 있다 |
| F-VOC-3 | 스페인어 또는 한국어로 검색할 수 있다 |
| F-VOC-4 | 사용자 단어를 등록, 수정, 삭제할 수 있다. 빈 값과 중복을 검사한다 |
| F-VOC-5 | 기본 단어는 읽기 전용이다 |
| F-VOC-6 | 구분 열은 글자 없이 색 점(기본 연보라, 내 단어 분홍)으로만 표시하고 범례를 둔다 |
| F-VOC-7 | "스페인어 가리기", "뜻 가리기"로 열을 가릴 수 있고, 가린 칸을 누르면 그 칸만 보인다. 가리기 설정은 유지된다 |
| F-VOC-8 | "섞기"로 현재 목록을 무작위로 섞고, "원래 순서"로 되돌린다. 섞은 순서는 저장하지 않는다 |
| F-VOC-9 | 줄을 누르면 단어 상세 창이 열린다. 내 단어는 상세 창에서 수정, 삭제한다 |
| F-VOC-10 | 뜻 앞에 소문자 품사 약어를 붙여 표시한다. 예: `n.m. 책`. 품사 열이나 배지는 두지 않는다 |
| F-VOC-11 | "약어 설명" 버튼으로 14개 품사 약어와 설명을 볼 수 있다. 닫기 버튼, 바깥 클릭, Esc로 닫는다 |
| F-VOC-12 | 사용자 단어 등록·수정 시 품사를 고르고, 명사일 때만 성별(남성, 여성, 양성, 공통성, 미분류)을 고른다 |

### 2.3 기본 단어

| 번호 | 요구사항 |
|---|---|
| F-DATA-1 | A1~A2 수준 기본 단어 500개를 `data/words.json`에 제공한다 |
| F-DATA-2 | 카테고리별 개수: 인사·기본 표현 40, 사람·가족 50, 음식·음료 70, 동물·자연 50, 집·생활 60, 학교·직업 50, 숫자·시간 60, 감정·성격 40, 기본 동사 50, 형용사·기타 30 |
| F-DATA-3 | 필드: id, spanish, korean, partOfSpeech, gender(명사만), category, level |
| F-DATA-4 | 철자, 악센트, 뜻을 확인하고 중복을 제거한다 |
| F-DATA-5 | 단어 수, 필수 필드, 중복, 품사·성별 값을 검증하는 코드를 둔다 |

### 2.4 퀴즈

| 번호 | 요구사항 |
|---|---|
| F-QUIZ-1 | 스페인어 단어를 보고 한국어 뜻을 맞힌다 |
| F-QUIZ-2 | 객관식 4지선다. 보기에는 품사 약어를 넣지 않고, 오답 보기는 같은 품사에서 먼저 뽑는다 |
| F-QUIZ-3 | 주관식 입력. 앞뒤 공백을 무시하고, 쉼표로 구분된 뜻 중 하나와 같으면 정답이다. 입력 앞의 품사 약어는 무시한다 |
| F-QUIZ-4 | 문제는 무작위로 출제한다. 문제 수(10/20/30)와 카테고리를 고를 수 있다 |
| F-QUIZ-5 | 답을 고르면 정답/오답을 바로 표시하고, 해설에 `스페인어 — 약어 뜻`을 보여 준다 |
| F-QUIZ-6 | 마지막에 점수와 정답률을 표시한다 |
| F-QUIZ-7 | 출제할 단어가 부족하면 안내 메시지를 표시한다 |

### 2.5 오답노트

| 번호 | 요구사항 |
|---|---|
| F-WRONG-1 | 퀴즈에서 틀린 단어를 자동으로 기록한다 (틀린 횟수, 마지막으로 틀린 날) |
| F-WRONG-2 | 오답 목록을 보여 주고, 단어를 목록에서 뺄 수 있다 |
| F-WRONG-3 | 오답 단어만으로 재시험을 본다. 재시험에서 맞힌 단어는 목록에서 빠진다 |
| F-WRONG-4 | 복습 결과를 저장한다 |

### 2.6 학습 통계

| 번호 | 요구사항 |
|---|---|
| F-STAT-1 | 총 퀴즈 횟수, 정답률, 학습한 단어 수, 오답 단어 수를 표시한다 |
| F-STAT-2 | 최근 퀴즈 정답률 그래프와 최근 기록 목록을 표시한다 |
| F-STAT-3 | 주간 학습 기록: 이번 주 총 학습 시간, 학습 일수(n일 / 7일), 월~일 막대그래프, 이전 주/이번 주/다음 주 이동 |
| F-STAT-4 | 한 주는 월요일부터 일요일까지다. 학습하지 않은 지난 날은 0분, 미래 날짜는 기록 없음("-")으로 표시한다 |
| F-STAT-5 | 학습 시간은 버튼 없이 자동으로 측정한다. 단어장, 퀴즈, 오답노트 화면에서만 측정한다 |
| F-STAT-6 | 다른 탭으로 가거나 창이 비활성화되면, 또는 5분 동안 입력이 없으면 측정을 멈추고, 다시 입력하면 재개한다 |
| F-STAT-7 | 날짜는 한국 시간 기준으로 나누고, 자정을 넘기면 날짜별로 나눠 기록한다 |
| F-STAT-8 | 여러 탭을 열어도 학습 시간이 중복으로 더해지지 않게 한다 |

### 2.7 데이터 저장

| 번호 | 요구사항 |
|---|---|
| F-SAVE-1 | 기본 단어는 `data/words.json`, 사용자 단어·오답·통계·학습 시간은 localStorage에 저장한다 |
| F-SAVE-2 | 새로고침해도 사용자 데이터가 유지된다 |
| F-SAVE-3 | 기본 단어와 사용자 단어를 구분한다 |
| F-SAVE-4 | 사용자 데이터를 임의로 초기화하지 않는다. 저장 공간이 부족하면 안내하고 기존 데이터는 그대로 둔다 |

## 3. 비기능 요구사항

| 번호 | 요구사항 |
|---|---|
| N-1 | 프레임워크, 백엔드, 외부 API, CDN, 웹폰트를 쓰지 않는다 |
| N-2 | GitHub Pages에서 서버 없이 동작한다. 상대 경로를 쓴다 |
| N-3 | 이모지를 프로젝트 어디에도 쓰지 않는다 |
| N-4 | 라이트 파스텔 글래스모피즘 디자인. 색상, 폰트, 버튼, 카드는 CSS 변수로 관리한다 |
| N-5 | 데스크톱 중심 반응형. 1024px 이하 아이콘 사이드바, 768px 이하 하단 탭 바 |
| N-6 | 텍스트 가독성을 확보하고, 과도한 애니메이션을 쓰지 않는다 |
| N-7 | 키보드로 주요 기능을 조작할 수 있다 |
| N-8 | Python 기초만 아는 학생도 읽을 수 있는 간결한 코드 |
| N-9 | 문서는 한국어, 코드 식별자는 영어 |
