# 테스트 계획

결과 열에는 실제로 실행한 테스트만 기록합니다. 실행하지 않은 항목은 "미실행"으로 둡니다.

## 1. 테스트 방법

- 자동 검사: `node tests/validate-words.js`
- 이모지 검사: 프로젝트 전체에서 이모지 유니코드 범위를 검색해 0건인지 확인
- 브라우저 테스트: 임시 정적 서버(`python -m http.server`)로 연 페이지를 Chrome에서 확인
- 배포 테스트: GitHub Pages 공개 URL에서 주요 흐름을 다시 확인
