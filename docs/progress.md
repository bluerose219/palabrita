  - 홈 카테고리별 학습에 "내 단어" 카드 추가
  - 품사 약어(소문자)를 뜻 앞에 표시, 약어 설명 창과 단어 상세 창 추가

  - 주간 막대그래프에서 날짜를 위로, 학습 시간을 아래로 이동
- 확인: 시안 스크립트는 Node 문법 검사만 했고, 브라우저에서 직접 동작을 확인하지는 않았습니다.

### 3단계: 기본 스페인어 단어 500개 구축 및 검증 (`feature/words-data`)

- `tests/validate-words.js`를 먼저 작성했습니다. 카테고리별 진행 상황(완료, 부족, 미작성)을 보여 주므로 중간에 멈춰도 어디까지 했는지 알 수 있습니다.
- 단어는 카테고리 묶음별로 작성하고 묶음마다 커밋합니다.

| 묶음 | 카테고리 | 상태 |
|---|---|---|
| 1 | greetings(40), people(50) | 완료 |
| 2 | food(70), nature(50) | 완료 |
| 3 | home(60), school(50) | 완료 |
| 4 | numbers(60), emotions(40) | 완료 |
| 5 | verbs(50), adjectives(30) | 완료 |

- 결과: 500개 작성, `node tests/validate-words.js` 통과 (오류 0건, 경고 0건)
- 구성: A1 413개, A2 87개. 명사 326개(남성 168, 여성 146, 공통성 9, 양성 3), 형용사 56, 동사 48, 동사구 2, 부사 14, 감탄사 8, 대명사 2, 접속사 2, 전치사 1, 기타 41
- 정확성을 위해 지킨 기준
  - 명사는 관사 없이 단수 기본형으로 썼습니다. 복수로만 주로 쓰는 단어(padres, pantalones, zapatos, gafas, matemáticas)는 복수형 그대로 두었습니다.
  - el agua, el aula, el hambre처럼 남성 관사를 쓰지만 여성인 명사는 여성(feminine)으로 표시했습니다.
  - 형태가 바뀌는 사람 명사(hermano/hermana 등)는 따로 등록하고, 형태가 같은 사람 명사(estudiante 등)는 공통성으로 표시했습니다.
  - 같은 철자는 한 번만 등록했습니다. 예: mañana는 부사 "내일"로만, tarde는 명사 "오후"로만 넣었습니다.
  - 객관식 보기가 헷갈리지 않도록 완전히 같은 뜻이 두 번 나오지 않게 했습니다. 예: esposa는 "아내", mujer는 "여자"
- 검증 코드 시험: 일부러 틀린 데이터 9종(중복, 약어 포함, 잘못된 level·품사·성별, 필드 누락, id 순서, 알 수 없는 필드)을 넣은 사본으로 실행해 9건 모두 오류로 잡히는 것을 확인했습니다.
- 단어 입력에는 저장소 밖의 임시 변환 스크립트를 썼습니다. 저장소에는 결과물인 `words.json`만 있으며, 앞으로는 `words.json`을 직접 고치면 됩니다.

### 4단계: 단어장 기능 구현 (`feature/vocabulary`)

- `js/storage.js`: 항목별 읽기/쓰기 함수, 깨진 값 보관(`키.broken`), 저장 실패 알림
- `js/vocabulary.js`: words.json 불러오기, 기본/사용자 단어 합치기, 필터·검색(악센트 없이 검색), 품사 약어 공통 함수, 약어 설명 창, 가리기(설정 저장)와 섞기, 상세 창, 등록·수정·삭제 폼, 같은 철자 처리
- `js/app.js`: 비동기 초기화, 공통 창 열기/닫기(바깥 클릭, Esc, 포커스 복원), 알림, 홈 화면을 실제 데이터로 연결, 홈 카드에서 단어장 필터로 이동
- `js/stats.js`: 한국 날짜 함수, 홈용 통계 요약 함수
- `index.html`, `css/style.css`, `css/responsive.css`: 단어장 화면, 상세 창, 단어 폼, 알림, 불러오기 오류 안내, 모바일 약어 설명 시트
- 사용자 결정 반영: 같은 스페인어는 뜻이 겹치면 막고, 뜻이 모두 다르면 확인 후 저장
- 홈 카테고리 카드는 "내 단어" 카드를 한 줄 전체로 두고 카테고리 10개를 모두 보여 주도록 바꿨습니다. 카드 11개를 2열에 두면 마지막 카드가 혼자 남기 때문입니다.
- 테스트는 Chrome에서 스크립트로 실제 클릭과 입력을 일으켜 확인했습니다. 스크린샷은 이번에도 시간 초과로 찍지 못했습니다.

### 5단계: 객관식·주관식 퀴즈 구현 (`feature/quiz`)

- `js/quiz.js`: 설정(유형, 문제 수, 범위), 단어 부족 안내, 객관식 보기 만들기, 주관식 채점, 피드백과 해설, 결과 화면, 숫자 키와 Enter 조작, 그만두기
- `js/wrong-answers.js`: 오답 기록(틀린 횟수, 마지막 날짜), 오답에서 빼기, 오답 목록, 재시험 시작 (목록 화면은 6단계)
- `js/stats.js`: 문제마다 정답률과 학습한 단어 저장, 퀴즈를 끝내면 기록 저장(최근 200개)
- 주관식은 사람마다 띄어쓰기가 달라서 공백을 모두 지우고 비교하도록 했습니다. 예: "아침식사"도 "아침 식사"의 정답
- 테스트: 객관식 10문제를 숫자 키로 풀어 보기 4개, 뜻 중복 없음, 약어 없음, 같은 품사 오답 보기(10문제 모두 3개)를 확인했습니다. 주관식 채점은 17가지 입력으로 확인했습니다.

### 6단계: 오답노트 및 학습 통계 구현 (`feature/wrong-answers-stats`)

- `js/wrong-answers.js`: 오답 목록(정렬), 목록에서 빼기, 객관식/주관식 재시험, 최근 재시험 결과
- `js/stats.js`: 통계 화면(카드 4개, 정답률 그래프, 최근 기록), 주간 학습 기록(주 이동, 미래 날짜 처리), 자동 학습 시간 측정 `Stats.timer`
- 측정 조건은 단어장/퀴즈/오답노트 화면, 탭이 보이고 포커스가 있을 때, 마지막 입력 후 5분 이내, 측정 담당 탭일 때입니다. 자정을 넘는 구간은 날짜별로 나눠 기록합니다.
- 사용자 요청으로 중간에 두 번 멈췄습니다. 멈출 때마다 커밋하지 않은 작업 범위를 보고했고, 이어서 진행했습니다.
- 테스트: 학습 시간 측정은 가짜 시계(`Stats.timer.now`)로 조건별 동작을 확인하고, 실제 시계로도 단어장 4초 측정, 통계 화면 0초를 확인했습니다. 테스트 전 학습 시간 값은 백업했다가 테스트 후 되돌렸습니다.

### 7단계: 반응형 디자인 및 기능 테스트 (`feature/responsive-test`)

- 5개 화면을 5개 폭(1280, 1024, 768, 400, 360px)에서 측정했습니다. 문서 가로 스크롤과 화면 밖으로 넘친 요소를 검사했습니다.
- 고친 것
  - 400px에서 단어 추가 창과 상세 창이 화면 오른쪽으로 넘치던 문제
  - 768px 이하에서 단어장 표가 가로로 스크롤되던 문제: 카테고리 열을 숨김(상세 창에서 확인 가능)
  - 768px 이하에서 오답노트 표의 날짜 열을 숨김
- 실제 두 탭 테스트로 학습 시간이 중복으로 더해지지 않는 것을 확인했습니다.
- 키보드 포커스 표시, 이름 없는 버튼, 콘솔 오류, 이모지, 외부 의존을 검사했습니다.
- Chrome 자동화의 스크린샷 기능은 7단계에서도 시간 초과로 쓰지 못했습니다. 레이아웃은 측정값으로만 확인했으므로, 배포 후 사람이 직접 눈으로 한 번 확인하는 것이 좋습니다.

### 7-2단계: 사용자 요청 추가 수정 (`feature/vocab-paging`)

7단계 이후 사용자 요청으로 여러 수정을 했습니다. 수정마다 시안(확인용 링크)을 먼저 보여 주고 확인받은 뒤 반영했고, 마지막에 한 번에 테스트하고 병합했습니다.

- 단어장: 30개씩 페이지 나누기와 번호 열. 페이지 이동은 "..." 없이 10개 묶음으로 바꾼 뒤, 마지막 페이지 표시와 선택 상자를 더하고, 디자인 시안 3개 중 밑줄 탭(시안 C) + 알약 선택 상자(시안 A)로 정했습니다.
- 카테고리: 선택 상자를 "전체"와 여러 개를 켤 수 있는 버튼으로 바꿨고, 퀴즈 출제 범위도 같은 방식으로 바꿨습니다.
- 외운 단어: 처음에는 구분 칸에 체크 상자를 넣었다가, 사용자 요청으로 별도의 "외운 단어" 열로 옮겼습니다. 저장 키 `palabrita.memorized`를 추가했습니다.
- 동사: 기본 동사 48개와 동사구 2개의 현재시제 형태를 `words.json`의 `present`에 넣고 검증 코드에 검사를 추가했습니다.
- 디자인: "알잘딱깔센 디자인" 스킬로 장식을 줄였더니 사용자가 너무 심플하다고 해서, 홈 디자인 시안 5개를 만들고 사용자가 고른 조합(시안 1 목록 + 시안 3 오늘의 단어 + 시안 4 3단계)으로 홈을 다시 구성했습니다. 아이콘과 막대 색은 보라색 한 가지로 통일했습니다.
- 학습 통계 그래프는 선 그래프에서 막대그래프로 바꿨고, 홈의 그래프는 뺐습니다.
- 상단 오답 배지를 빼고 약어 설명 버튼(아이콘만)을 상단으로 옮겼습니다.
- 테스트: 기능 26개 항목과 5개 화면 x 5개 폭 레이아웃을 확인했습니다. 테스트 전 저장 데이터는 모두 백업했다가 그대로 되돌렸습니다.
