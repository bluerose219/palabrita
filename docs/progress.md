# 진행 기록

실제로 수행한 작업과 문제 해결 내역을 날짜순으로 기록합니다.

## 2026-10-21

### 0단계: HTML 디자인 시안

- 사용자가 첨부한 글래스모피즘 대시보드 이미지를 바탕으로 단일 HTML 시안을 만들었습니다. 시안은 프로젝트 밖의 임시 파일이며 저장소에는 포함하지 않았습니다.
- 사용자 피드백으로 반영한 내용
  - 로고 색을 보라색 한 가지로 통일
  - 단어장에 스페인어/뜻 가리기와 섞기 추가
  - 단어장 관리 열 제거, 열 이름 "한국어 뜻"을 "뜻"으로 변경, 구분 열은 색 점으로만 표시
  - 홈 카테고리별 학습에 "내 단어" 카드 추가
  - 품사 약어(소문자)를 뜻 앞에 표시, 약어 설명 창과 단어 상세 창 추가
  - 학습 통계에 주간 학습 기록과 자동 학습 시간 측정 추가. 무입력 정지 기준을 60초에서 5분으로 변경
  - 주간 막대그래프에서 날짜를 위로, 학습 시간을 아래로 이동
- 확인: 시안 스크립트는 Node 문법 검사만 했고, 브라우저에서 직접 동작을 확인하지는 않았습니다.

### 1단계: 프로젝트 폴더 구조 생성 및 문서 초안 작성

- Git 저장소를 `main` 브랜치로 초기화했습니다.
- 지시서의 폴더 구조대로 파일 골격을 만들었습니다. JS, CSS, `index.html`, `words.json`, `validate-words.js`는 다음 단계에서 채울 골격입니다.
- README.md, AGENTS.md, docs 문서 6종, data/README.md, Claude 스킬 2종 초안을 작성했습니다.
- 빈 폴더(`assets/images`, `assets/icons`)는 Git이 추적하도록 `.gitkeep`을 넣었습니다.
